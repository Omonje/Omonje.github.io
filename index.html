Maintenance Request Routing

  • n8n
  • Airtable
  • OpenAI

Classifies each tenant request by category and urgency the moment it arrives, then hands it to a contractor marked available for that category and notifies both sides. If the model returns something unusable, the request defaults to General and Routine instead of stalling.

  1. Tenant submits a request
  2. Model sets category and urgency
  3. Route to an available contractor
  4. Notify tenant and contractor
